# Simple Calculator

A simple command-line calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Error handling for division by zero
- User-friendly menu

## Technologies Used
- Python

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Run the following command:

python calculator.py
